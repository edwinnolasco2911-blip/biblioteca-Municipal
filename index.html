Demostración

Solicitud de reserva

Elige un libro y completa tus datos para probar cómo funcionaría una solicitud de reserva.

Esto es solo una demostración. La solicitud no se envía a la Biblioteca Municipal ni se reserva ningún libro. Durante las pruebas usa datos ficticios (por ejemplo, “Ana Prueba” y “ana@ejemplo.com”). No escribas información personal real.

Datos de la solicitud

También puedes elegirlo con el botón “Reservar libro” del catálogo.

¿Cómo funciona esta demostración?

  1. Elige un libro en el catálogo o en la lista.
  2. Escribe un nombre y un correo ficticios.
  3. Pulsa “Enviar solicitud”: el sitio solo comprueba que los datos tengan sentido.

No existe conexión con la biblioteca, con una base de datos ni con un servidor. No se guarda ningún dato y la disponibilidad mostrada es solo un ejemplo.
